About

I'm a QA Engineer focused on software quality, test automation and quality engineering. My work goes beyond executing test cases — it starts with understanding requirements and user stories, assessing risk, and designing test coverage that actually protects the release.

My background spans UI testing with Java and Selenium, API testing with Postman, database validation with SQL, and performance testing with K6 and Grafana — alongside Angular testing (Jasmine, Karma), Azure DevOps, and agile methods such as Scrum, Kanban, TDD and BDD. I'm currently expanding into modern automation architecture with Playwright and TypeScript.

As an ISTQB Certified Tester (CTFL), I focus on identifying risk early and working closely with development and product teams to ship reliable, user-focused software. I'm based in Kaiserslautern, Germany, after several years contributing to QA processes and test automation initiatives in Brazil.
